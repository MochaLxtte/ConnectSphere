## Source mapping

| Component | Source | Responsibility |
| --- | --- | --- |
| HTTP composition | `backend/src/app.ts`, `backend/src/runtime-app.ts` | Mount routes and wire dependencies |
| Authentication | `backend/src/modules/auth/` | Verify Supabase tokens, sessions, trusted profiles and access policies |
| Event workflow | `backend/src/modules/events/` | Drafts, submission, initial assignment, clarification, review and history |
| Venue planning | `backend/src/modules/venues/` | Catalogue, search, availability, suitability, booking and blocks |
| Workflow HTTP boundary | `backend/src/modules/events/workflow-http.ts` | Shared request authentication, roles, identifiers and errors |
| Shared workflow support | `backend/src/modules/events/workflow-support.ts` | Transaction and event helpers also consumed by venue workflows |
| Database pool | `backend/src/db/pool.ts` | Server-side PostgreSQL connections |
| Health endpoints | `backend/src/app.ts` | Liveness and database readiness |

The API is one process. Domain services execute parameterised SQL and share transaction clients where required. The browser exchanges Supabase credentials for an access token and then establishes an HttpOnly API session. Application data access goes through Express. Supabase hosting does not imply that the frontend/API have been deployed.

Equipment, registration and notification tables do not imply implemented application modules. Coordinator Lead, Safety Officer, multi-venue arrangements and tentative holds remain consultation proposals. Technical Support Staff currently have venue-calendar access; equipment workflows are future work.

## Re-export

Use Node.js and Mermaid CLI (`@mermaid-js/mermaid-cli`), with Chromium available to Puppeteer. For each `.mmd` file run:

```text
mmdc -i c1-system-context.mmd -o exports/c1-system-context.png -c mermaid-config.json --size 2400 -s 2
```

Repeat for C2 and C3. When supplying an existing Chromium installation, pass `-p` with a local Puppeteer JSON configuration containing `executablePath`. Keep machine-specific paths outside the repository. Visually check every export after changing a source. The PDF packages the three PNGs with view titles and source metadata.

The view boundaries follow the [C4 container](https://c4model.com/diagrams/container) and [component](https://c4model.com/diagrams/component) definitions. A component view expands one container.
