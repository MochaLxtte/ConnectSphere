# Scrum process and evidence

Submission Folder 4 follows four sprints from the first saved event request to venue booking, equipment reservations, registration and safety approval. The first two reviews each accepted **24 SP**. The team carried unfinished stories at full points, revisited them against their criteria and accepted **63 SP** in each of the final two sprints.

Start with the [WS4 evidence index for Sprints 1–2](ws4-evidence/README.md) for planning, early difficulties, review decisions and observed improvements. Use the [WS5 evidence index for Sprints 3–4](ws5-evidence/README.md) for the customer changes, later delivery and final-sprint recordings.
