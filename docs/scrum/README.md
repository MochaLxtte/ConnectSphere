## Editing conventions

Write one clear current summary and link detailed evidence. Record event dates separately from dates when evidence was supplied. Each member supplies their own standup and retrospective contribution. Meeting attendance does not establish estimation votes or an agreed action. Preserve original acceptance criteria and later customer changes as distinct versions.

Historical checkpoints are preserved in linked archives; existing evidence files and the test-run ledger retain their locations. Use the [release accounting](release-burndown.md) for point interpretation. No synthetic burndown or meeting outcome is created during documentation cleanup.
