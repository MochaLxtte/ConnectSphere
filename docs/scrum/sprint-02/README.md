# Sprint 2

The team selected **12 stories / 43 story points (SP)** for **20 September–3 October 2026**. On 3 October it accepted **seven stories / 24 SP** and carried **five stories / 19 SP**. Assignment, calendar, booking submission, staff decisions, conflict checks, operational blocks and reopening decided requests were accepted. Submission, draft editing, catalogue, search and suitability carried into Sprint 3. [Review decisions](review.md) · [Meeting accounts](evidence/README.md)

<a id="team-input-needed"></a>

## Sprint goal

Enable submitted requests to reach an assigned coordinator, and enable coordinators to identify suitable available venues from a maintained catalogue, request bookings, and receive Venue Staff decisions without conflicting bookings.
