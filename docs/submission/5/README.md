# 5. Summary slide deck

**Status: pending the course template and final project results.**

Create a self-contained slide deck using the template released in eLearn by Week 11, then place the exported PDF in this folder. The deck will not be presented, so explanations and evidence references must make sense on their own.

Use the required template to explain the team's work against all eight rubric areas: Scrum process and evidence; estimation and planning; user stories and customer needs; system design; working software; testing and traceability; code quality and CI; accountability and explainability.

Draw on evidence across all sprints, including changes made after feedback, actual velocity, completed workflows and test outcomes. Refer to numbered submission folders and specific artifacts so evidence can be found easily.
